# Miro Kitchen — PWA

تطبيق ميرو كيتشن (Home Cooking) كتطبيق ويب قابل للتثبيت على الهاتف.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | التطبيق نفسه (الصور جواه كما هي) |
| `manifest.json` | بيانات التطبيق: الاسم، الأيقونات، الألوان، اختصارات الأيقونة |
| `sw.js` | Service Worker: يخلّي التطبيق يشتغل بدون نت ويسمح بالتثبيت |
| `icons/` | أيقونات التطبيق (من اللوجو) |
| `.nojekyll` | يمنع GitHub Pages من معالجة الملفات |

## الرفع على GitHub Pages

1. أنشئ Repository جديد على GitHub (مثلاً `miro-kitchen`).
2. ارفع **كل** الملفات والمجلد `icons` في الجذر (نفس مستوى `index.html`).
3. من `Settings` ← `Pages` ← Source: `Deploy from a branch` ← Branch: `main` و Folder: `/ (root)` ← Save.
4. بعد دقيقة هيظهر الرابط: `https://USERNAME.github.io/miro-kitchen/`

## التثبيت على الهاتف

افتح الرابط في **Chrome**: هيظهر شريط «ثبّت تطبيق Miro Kitchen» وزر 📲 في الهيدر،
وكمان من قائمة Chrome ⋮ هتلاقي «تثبيت التطبيق» بجانب «إضافة إلى الشاشة الرئيسية».
على iPhone: Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية.

> التثبيت لا يعمل إلا من رابط `https://` (مثل GitHub Pages)، ولا يعمل لو فتحت الملف مباشرة من الهاتف أو من واتساب.

## تحديث التطبيق

بعد تعديل المنتجات/الصور من لوحة الإدارة واختيار «💾 حفظ ملف»:
سمّي الملف الناتج `index.html` وارفعه مكان القديم. الباقي (manifest و sw.js والأيقونات) لا يحتاج أي تغيير،
والتطبيق بيتحدّث تلقائياً عند فتحه وفيه إنترنت.

## سحب الشاشة للرجوع

اسحب الشاشة لليمين أو لليسار في أي صفحة داخلية (الأقسام، المنتجات، السلة، التقييمات، الصور، الإدارة) للرجوع.
زر الرجوع في الهاتف بيرجّع للصفحة السابقة كمان بدل ما يقفل التطبيق.
